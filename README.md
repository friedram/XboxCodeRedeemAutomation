# XboxCodeRedeemAutomation
Simple Python program that takes a *.DOCX with Xbox codes in it and redeems the codes by automating the mouse movement and clicking.
Read.me<br>
What is this? <br>
When you have many Xbox codes that you want to redeem, using the Xbox PC application is a reliable way to do so.<br>
pyautogui is simply pushing the individual buttons needed in the Xbox app at the right coordinates, copies the<br>
codes out of a word document in a *.docx format. I have a different program that I run to strip out the correct<br>
codes from a larger document and place the codes into the document.<br>
Learn more about pyautogui here https://www.youtube.com/watch?v=lfk_T6VKhTE<br>
ChatGPT o3-mini was used in the creation of this code<br>
You MUST modify the coordinates_first_run and clone some of the coordinates for coordinates_subsequent to make it <br>
work on your PC.<br>
